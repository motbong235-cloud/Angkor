សំណួរញឹកញាប់

ភាគច្រើននៃ order ត្រូវបានដឹកជញ្ជូនក្នុងរយៈពេល 10–60 វិនាទី បន្ទាប់ពីបង់ប្រាក់ជោគជ័យ។

ប្រព័ន្ធនឹងផ្ទៀងផ្ទាត់ ID មុនពេលបង់ប្រាក់។ បើ ID មិនត្រឹមត្រូវ នឹងមិនអាចបញ្ជាទិញបានទេ។
បាទ។ បន្ទាប់ពីទិញ អ្នកនឹងទទួល Order Code ហើយអាចតាមដាននៅទំព័រ “តាមដាន Order”។
